======================================================================================
1. Login
API Type:POST
URL:https://localhost:7193/api/Auth/Login
Request:
{
    "Email":"User01Email@gmail.com",
    "Password":"User01 Password"
}
---------------------------------------------------------------------------------------
Response:
{
    "data": null,
    "message": "Login Sucessfull",
    "status": true
}
======================================================================================
2. Register
API Type:POST
URL:https://localhost:7193/api/Auth/Register
Request:
{
    "Email":"User01Email@gmail.com",
    "Password":"User01 Password",
    "Name" : "User01 Name"
}
---------------------------------------------------------------------------------------
Response:
{
    "data": null,
    "message": "This user already exist, Please Register with new user detail",
    "status": false
}
